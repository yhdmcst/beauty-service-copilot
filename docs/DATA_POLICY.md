# 数据与上传边界

## 随项目提供

`data/contest/`是赛题提供的虚构MOCK业务数据的字段清理副本。保留138个会话的关联、998条消息、113笔订单和80张工单，供工作台本地演示。

清理副本去掉无关账号、实名和重复原始聊天字段，昵称替换为一致的“演示买家编号”。消息中的手机号、邮箱和显式账号文本有额外掩码规则。本机原始数据没有修改。

`evaluation/holdout_v2/`由清理数据重新生成20条开发和30条待标注模板。标签为空；不包含原人工标签或原计时结果。

模拟知识均用于测试门禁，缺审核标记时不得用作商品配方、疗效或商家政策事实。

## 不随项目提供

- 本机 `.env`、密钥和凭据。
- Python虚拟环境、Node依赖、浏览器和下载缓存。
- 运行数据库、个人审核记录、人工标注和效率计时。
- 官方原始Excel、Word说明、品牌PPT模板。
- 完整历史模型请求日志及含无关账号字段的原始数据。

## 公开授权

比赛说明允许参赛使用MOCK数据，不等于已确认允许在公开GitHub仓库再分发。本次没有取得额外授权，建议先Private。数据、演示截图和PPT中仍有赛题来源内容，公开前应确认主办方允许。

源码许可证尚未指定；第三方依赖的许可与本项目数据授权分别处理。不要把本仓库的存在解释为真实品牌背书或生产数据授权。

## 新的真实业务数据

应使用自己有权处理的资料。不要把支付账户、电话号码、实名或医疗图片直接提交GitHub；运行时数据库默认忽略。确认字段权限、用途和访问控制后再接平台。
