# 数据与场景知识

## 虚构业务数据

`data/contest/`为赛题提供的虚构MOCK业务数据，按工作台所需字段整理。包含138个会话、998条消息、113笔订单与80张工单。

数据保留会话、订单和工单的关联，昵称统一为演示编号。无关账号、实名及重复原始字段未保留，消息中的联系方式采用掩码规则处理。

## 场景知识示例

`data/beauty_knowledge/`包含商品、护肤、政策、共情表达和人工处理流程示例，用于展示知识检索、适用范围筛选与回复生成。

示例不依赖真实品牌审核。处理流程帮助客服组织核查动作，商品与政策内容保留来源和审核状态。作品据此展示流程辅助与事实引用的区别，避免将示例政策写成已发生的订单结果。

## 标注模板与运行记录

`evaluation/holdout_v2/annotation_pack.json`包含20条开发和30条待标注模板，初始没有人工标签。新增分析、审核、任务和评估记录保存在本机 `data/runtime/`。

提交目录提供固定工程协议和评测结果，不包含个人数据库、模型密钥、虚拟环境、模型权重或完整开发日志。

## 使用范围

数据与截图用于本作品参赛展示，沿用赛题材料的使用条件。公开再分发时按主办方要求处理。第三方代码与模型按各自许可使用，详见 [第三方说明](../THIRD_PARTY_NOTICES.md)。
