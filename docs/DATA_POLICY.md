# 数据说明

## 业务数据

`data/contest/`为赛题虚构业务数据的清理副本，包含138个会话、998条聊天、113笔订单及80张工单，保留会话关联关系。

无关账户、实名和重复字段已移出，昵称统一替换为演示编号。消息中的电话、邮箱及显式账号文本另作掩码。本机原始资料保持不变。

`data/beauty_knowledge/`提供演示知识，用于检索和支持检查。未审核内容不作真实商品配方、功效或商家政策依据。

## 标注与运行记录

`evaluation/holdout_v2/`包含20条开发及30条待标注模板，标签为空。原人工标注、回复复核和效率计时保存在本机，不随源码提供。

首次运行会在 `data/runtime/` 创建当前机器的数据库，用于保存分析、审核及任务。私有 `.env`、数据库、依赖环境、模型权重、官方原始附件及完整请求日志均未打包。

## 使用权限

赛题资料按比赛允许的范围使用。公开发布时，需要另行确认数据再分发权限；字段清理本身不改变授权。项目源码许可证尚未指定，第三方依赖及权重按各自许可获取和使用。

接入真实业务数据前，应确认用途、字段权限和访问控制，个人账户、联系方式及审核记录不提交到公开仓库。
