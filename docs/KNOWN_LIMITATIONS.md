# 使用限制

- 多轮承接覆盖有限表达。多个订单或事项对应不明确时，需要客服确认。
- 情绪判断受表达和标签口径影响。基础情绪、业务场景及风险分开显示，具体回复仍需人工审核。
- 默认知识是演示资料，真实品牌政策和商品结论需要有审核过的依据。
- 当前使用文本模型。图片消息记录与附件文件分开处理，尚未接入图片内容识别。
- 系统不执行真实退款、补发、改址或客户消息发送，也不作医疗诊断和商品真假鉴定。
- 当前部署面向本机演示，缺少生产级鉴权、租户隔离和平台接口。服务默认只监听回环地址。
- 本轮交付在Windows环境检查，其他操作系统和设备需单独验证。远程3090只确认过设备及模型列表，旧版Ollama生成超时，未获得远程推理性能结论。

模型结果与人工复核范围见 [评估说明](EVALUATION.md)。比赛前应在实际使用的电脑完成安装、预热和断网走查。
