## 不变的主线

辅助美妆电商人工客服看清服务轨迹、跟上未解决事项、判断当前诉求和服务风险。聊天、订单、工单融合形成有来源的判断和下一步；共情回应具体等待、顾虑和重复说明负担。界面以实际接待为第一屏。

每个优化至少回答四件事：它对应哪条赛题要求；减少什么实际客服负担；增加哪些模型调用/Token/依赖；如何证明有效、有没有退步。无法回答时先作隔离实验，不因开源项目名气直接接入。

## 考察与交付

功能完整性/实用性、智能分析准确度、技术创新/场景价值是三项核心考察。性能/成本是加分方向，应在效果不退步时测量。没有官方数值权重，内部91分不是官方分或准确率。

初赛PPT包含背景与洞察、技术方案、核心演示、落地价值、未来规划；用户不需要团队/分工页。实际视频须录真实操作。决赛再补Agent设计内容、现场Demo与源码/运行指南ZIP。

多模态、真实品牌知识、生产平台接口、多人标注、固定30/20/12样本、完整人工效率试验都是扩展/评估选择，不擅自升级成官方报名条件。
