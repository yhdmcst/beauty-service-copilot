| 文件 | 用途 |
| --- | --- |
| [contest_presentation.pptx](contest_presentation.pptx) | 18页可编辑展示PPT |

展示以时点证据和事项连续性为核心创新，围绕退款接待串联证据、回复与人工跟进，再说明技术工作流、验证结果和作品价值。操作截图来自虚构数据演示；正文呈现当前固定协议与生成时延，历史成本对照置于备注和答辩补充说明。

实际演示视频需在运行Demo后录制。现场准备见 [提交清单](../docs/SUBMISSION_CHECKLIST.md)，启动步骤见 [运行指南](../docs/QUICKSTART.md)。
