# 美妆客服共情副驾

美妆电商客服工作台，将聊天、订单和售后工单放在同一页面，帮助客服了解当前问题、起草回复、跟进服务风险。

版本：V10（`compact-v10-service-continuity-3`）。

## 运行

使用Python 3.11、Ollama和 `qwen3:8b`。首次安装、启动和现场演示步骤见 [运行指南](运行指南.md)。准备好依赖和模型后，双击 `start_demo.cmd` 打开工作台。

| 页面 | 主要操作 |
| --- | --- |
| 工作台 `/workbench` | 查看服务记录，生成建议，编辑审核回复，创建跟进任务 |
| 风险看板 `/dashboard` | 查看预警，认领任务，记录处理进度 |
| 评估页 `/evaluation` | 标注样本，记录效率对照 |

## 主要功能

- 按选定消息查看聊天、订单和工单。历史回放排除后续记录，缺失状态保留为未知。
- 识别当前诉求和未解决事项，区分基础情绪与业务场景，复用消费者已经提供的信息。
- 用本地Qwen生成回复草稿和下一步建议，显示依据、待核项及调整记录。
- 风险事项先登记再生成回复，由客服认领、备注和更新状态。

系统保存辅助建议和本地任务。对客回复由客服审核，退款、补发和改址仍在实际业务系统中办理。

## 项目结构

```text
src/                    数据处理、Agent、工作流和API
frontend/               页面及本地静态资源
data/                   虚构业务数据与演示知识
evaluation/             评测脚本、协议和标注模板
tests/                  自动化测试
scripts/                启动、模型检查和开发工具
docs/                   技术说明、评估及数据说明
.env.example            本地模型配置示例
运行指南.md             安装和现场操作步骤
```

工作流由LangGraph编排，采用Flask、Socket.IO和SQLite，默认使用词法检索及进程内缓存。运行不依赖Node、Docker、Redis或Qdrant服务。

技术资料见 [文档目录](docs/README.md)，第三方来源见 [组件说明](THIRD_PARTY_NOTICES.md)。模型效果、测试和使用限制见 [评估说明](docs/EVALUATION.md)。
